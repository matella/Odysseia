# `places/` — édition manuelle des lieux (§3.3)

L'utilisateur nomme ses lieux récurrents (« Maison », « Bureau ») — ce que le
geocoding « ville + POI majeurs » ne résout pas (§3.2).

Ces `user_place` (§5.2) sont rattachés **géographiquement**, jamais par id
d'import : ils survivent à tout ré-import.
